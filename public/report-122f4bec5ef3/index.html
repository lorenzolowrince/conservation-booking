What this is about

The new online booking system for the 7 conservation areas (DVCA, MBCA, ICCA, SCCA, TRCA, INFAPRO, INIKEA) has been built and is already working online. It lets visitors browse conservation areas and book stays, and lets staff manage bookings from an admin dashboard.

Right now the system is running on a completely free trial setup while it's being tested. This proposal asks for approval to spend a small monthly amount so the website runs reliably for real visitors and staff, instead of staying on the free trial setup indefinitely.

The one problem the free setup has

To keep the website free, the hosting provider "puts the website to sleep" after 15 minutes with no visitors. The next person to open the site then has to wait up to about a minute for it to "wake up" before the page appears — similar to a computer waking from sleep mode.

This is fine for internal testing, but is not the experience we want for real visitors deciding whether to book a stay, or for staff who need the admin dashboard to open promptly during work hours.

What the money is for

The RM 29/month upgrades the website's hosting plan to "always-on," which removes the sleep delay entirely. This is the only paid item in this proposal.

Looking further ahead

The booking database is currently free and, at the traffic levels expected for this system, is likely to remain free for a long time. If visitor numbers grow substantially in future, the database may eventually need a small paid upgrade as well — estimated at roughly RM 8–50/month (USD $2–12) depending on actual usage at that time. This is not part of what's being requested now — it's flagged here only so it isn't a surprise later, and would come back as a separate request if and when it's actually needed.
